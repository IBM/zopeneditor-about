IBM Bob™ Premium Package for Z integration

IBM Z Open Editor is part of the IBM Bob™ Premium Package for Z. This premium package extends IBM Bob by providing agents that help you analyze, explain, and develop mainframe applications more efficiently. Key use cases include:

  • Accelerate mainframe development with AI and automation.
  • Modernize applications and build new enterprise services.
  • Extract business logic to improve understanding of legacy code.

Z Open Editor is included in the package and unlocks most Advanced Capabilities when it runs as part of the Premium Package for Z. When Z Open Editor detects that it is running in the Premium Package for Z, it automatically performs an entitlement check. The results are reported on the Welcome page together with the unlocked Advanced Capabilities. A set of tools and skills is then registered with IBM Bob and made available in the Z Code and Z Architecture modes.

Z Open Editor also provides access to its its MCP server in the Premium Package for Z. The MCP server can be configured as described on the Agent Mode page. Although MCP tools provide additional capabilities, configuring the MCP server is optional. The following sections describe the tools that are available in the Premium Package for Z without MCP server configuration. To access the complete set of tools described in the IBM Z Open Editor MCP Tools reference page, configure the MCP server.

Advanced Premium Package Capabilities

This section describes the capabilities that IBM Z Open Editor contributes to the IBM Bob Premium Package for Z. These capabilities integrate with the two main modes of the Premium Package, Z Code mode and Z Architect mode. Capabilities from IBM Z Open Editor can be combined with the workflows, skills, and tools available in these modes.

Z Open Editor provides these capabilities through tools and skills. The tools correspond to the MCP tools provided by the Z Open Editor MCP server but do not require an MCP server configuration. They are integrated directly into the Bob Premium Package for Z. The same applies to the skills listed in this section. Z Open Editor contributes these skills to the package, making them available directly in Z Code mode and Z Architecture mode.

Examples of these integrations include:

  • Use the z-coding-standards-skill-builder in Z Code mode to define ZCodeScan rules files.
  • Run the impact-analysis skill in Z Architecture mode, which combines the zopeneditor-cobol-get-data-flow tool with the capabilities provided by the skill.
  • Troubleshoot an IBM Dependency Based Build (DBB) pipeline in Z Code mode by using the dbb-pipeline-troubleshoot skill contributed by Z Open Editor.

The following sections list all MCP tools and skills that IBM Z Open Editor registers with the IBM Bob AI assistant.

Z Architect mode

Bob Tools

Tools that provide data directly from the Z Open Editor language servers.

Tool nameTitleDescription
zopeneditor-cobol-get-data-flowGet COBOL Data FlowTraces data flow for a specific COBOL data item and returns a graph representation that shows how the item is modified throughout the program. Use this tool to analyze the impact of modifying COBOL data items or to understand how they are used.
zopeneditor-cobol-get-program-control-flowGet COBOL Program Control FlowRetrieves parsed control flow data from the COBOL Language Server for analysis of program structure and execution paths. Returns a graph of sections and paragraphs, including their names, line numbers, and edges that show control flow relationships (Fall Through, PERFORM, and GO TO).
zopeneditor-get-embedded-languagesDetect embedded programming languagesDetects embedded languages in a COBOL or PL/I file. Identifies whether a program contains CICS, SQL, IMS (DLI), or MQ operations.
zopeneditor-pli-get-program-control-flowGet PL/I Program Control FlowRetrieves parsed control flow data from the PL/I Language Server for analysis of program structure and execution paths. Returns a graph of procedures and packages, including their names, line numbers, and edges that show control flow relationships.
